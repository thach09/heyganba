# Quản trị

JWT yêu cầu ROLE_ADMIN ở server; người học thường nhận 403, chưa đăng nhập nhận 401. Có duyệt nội dung, thao tác từ vựng/chữ Hán/bài tập, quản lý tài khoản, audit log và 2FA. Giới hạn ghi giữ 30/phút/admin. Nhập giáo trình số lượng lớn phải dùng Flyway. Trường Pinyin và phồn thể dùng đúng tên và nghĩa, mặc định nội dung mới chờ duyệt.
